# UI/UX 交互设计规范交付指南

## 设计原则

界面应以内容和任务为中心，通过稳定的层级、间距和反馈降低理解成本。

## 信息层级

- 页面只保留一个明确的主任务。
- 标题、正文和辅助信息形成可预测的视觉层级。
- 通过留白组织内容，避免依赖过多装饰分隔。

## 布局规范

| 场景 | 建议 |
| --- | --- |
| 页面边距 | 保持一致并预留呼吸空间 |
| 内容宽度 | 控制单行阅读长度 |
| 组件间距 | 使用统一的间距尺度 |

## 交互反馈

操作状态应及时、明确且克制。加载、成功和失败反馈不得改变页面主要布局，也不应遮挡正在处理的内容。

## 可访问性

文本与背景需保持足够对比度；键盘焦点清晰可见；图标按钮应提供可理解的辅助名称。
